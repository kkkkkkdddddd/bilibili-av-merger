# B 站音视频合并工具

一个 Windows 桌面小工具，用来把下载后分开的画面和声音合并成一个 MP4。工具调用本机的 FFmpeg，直接复制两条轨道，保留源文件的画质和音质。

## 运行环境

- Windows
- 带 Tkinter 的 Python 3.8 或更高版本。启动文件支持默认路径的 Anaconda 和 Windows Python 启动器。
- FFmpeg。确保在命令行运行 `ffmpeg -version` 能看到版本信息。安装中的 `ffprobe.exe` 可用于显示合并进度。

## 使用方法

1. 将工具文件夹放在视频和音频所在目录的下一层。比如，素材放在 `D:\IDMDownload`，工具放在 `D:\IDMDownload\音视频合并工具`。
2. 双击 `打开音视频合并.cmd`。启动文件会打开 `merge.pyw` 的图形界面。也可以在工具目录里运行 `python merge.pyw`。
3. 从「B 站文件配对」里选择一组，界面会填入视频、音频和建议的输出路径。刚下载的新文件可以点「重新扫描」更新。文件名已经改过时，可以分别点「选择…」手动指定视频和音频。
4. 确认输出位置，点击「开始合并」。完成后可以点击「打开输出位置」，在资源管理器中定位生成的 MP4。

自动配对以文件名的前两段数字识别同一组素材。例如，`123456-1-30032.mp4` 和 `123456-1-30232.m4a` 会配成一组。同组有多份候选时，请手动选择对应轨道。

输出默认保存在视频所在目录，文件名以 `_合并.mp4` 结尾。同名文件已存在时，自动建议带序号的新文件名。

## 合并命令

```powershell
ffmpeg -n -i "video.mp4" -i "audio.m4a" -map 0:V:0 -map 1:a:0 -c copy -movflags +faststart "output.mp4"
```

`-map 0:V:0` 取第一个文件的第一条实际视频轨道，`-map 1:a:0` 取第二个文件的第一条音轨。两条轨道都通过 `-c copy` 直接写入 MP4，因此输入的编码需要与 MP4 容器兼容。如果合并失败，可在窗口中查看 FFmpeg 的错误信息。 [FFmpeg 文档](https://ffmpeg.org/ffmpeg.html#Streamcopy)
